Optional Persian font (recommended for fa_IR sites)
---------------------------------------------------
1. Download Vazirmatn (free, OFL licence): https://github.com/rastikerdar/vazirmatn
2. Take the variable font file and name it:  Vazirmatn-Variable.woff2
3. Put it in this folder.

The plugin detects the file automatically. Without it, the UI falls back to
Segoe UI / Tahoma, which already render Persian correctly.
